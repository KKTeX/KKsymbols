\newcommand{\lowerletter}{m}

% Log-only route checks. These exercise full expansion without depending on
% visual measurements or on a particular font.
\makeatletter
\newcommand{\KKSsmall}[1]{\def\KKSactual{SMALL}\typeout{KKS-ROUTE:SMALL}}
\newcommand{\KKSnormal}[1]{\def\KKSactual{NORMAL}\typeout{KKS-ROUTE:NORMAL}}
\newcommand{\KKSexpect}[2]{%
  \def\KKSactual{UNSET}%
  \kks@autolowercase@select{\KKSsmall}{\KKSnormal}{#2}%
  \def\KKSexpected{#1}%
  \ifx\KKSactual\KKSexpected\else
    \PackageError{test-autolowercase}{Expected #1 route, got \KKSactual}{}%
  \fi}
\KKSexpect{SMALL}{m}%
\KKSexpect{NORMAL}{abc}% automatic routing is for one letter only
\KKSexpect{NORMAL}{viii}% multi-letter lowercase remains on the normal path
\KKSexpect{SMALL}{\lowerletter}%
\KKSexpect{NORMAL}{\Rrnum{8}}% fully expands to viii
\KKSexpect{SMALL}{\Rrnum{1}}% fully expands to i
\KKSexpect{NORMAL}{\Rrnum{2-1}}% real KKran expands this to the multi-token ii-1
\KKSexpect{SMALL}{\alphabetarray{2}}% fully expands to b
\KKSexpect{SMALL}{\alphabetarray{-1}}% KKran negative index expands to z
\KKSexpect{NORMAL}{\lowerroman}% nested expansion reaches multi-letter \Rrnum
\KKSexpect{SMALL}{\Large m}% font-size command is safely ignored for matching
\KKSexpect{NORMAL}{A}%
\KKSexpect{NORMAL}{1}%
\KKSexpect{NORMAL}{a1}%
\KKSexpect{NORMAL}{あ}%
\KKSexpect{NORMAL}{\Rrnum*{8}}% fully expands to VIII
\KKSexpect{NORMAL}{\alphabetarray*{2}}% fully expands to B
\KKSexpect{NORMAL}{\alphabetarray{27}}% expands to empty
\KKSexpect{NORMAL}{}%
\makeatother

\section*{Automatic lowercase sizing (On)}

Each adjacent pair should have the same content size: automatic on the left,
explicit star on the right.

\noindent
\fbox{\maru{m}}\fbox{\maru*{m}}\quad
\fbox{\kuromaru{\lowerletter}}\fbox{\kuromaru*{\lowerletter}}\quad
\fbox{\seihou{w}}\fbox{\seihou*{w}}\quad
\fbox{\hishi{m}}\fbox{\hishi*{m}}\quad
\fbox{\kakko{m}}\fbox{\kakko*{m}}

\medskip
\noindent Diamond lowercase paths must preserve aspect ratio and stay inside
the diamond, including wide letters and white-on-black variants:\par
\fbox{\hishi{m}}\fbox{\hishi{w}}\fbox{\maruhishi{m}}\fbox{\maruhishi{w}}\quad
\fbox{\kurohishi{m}}\fbox{\kurohishi{w}}%
\fbox{\kuromaruhishi{m}}\fbox{\kuromaruhishi{w}}

\medskip
\noindent KKran expansion: one-letter results are automatic; multi-letter
Roman numerals retain normal sizing unless explicitly starred:\par
\fbox{\maru{\Rrnum{1}}}\fbox{\maru*{\Rrnum{1}}}\quad
\fbox{\maru{\Rrnum{8}}}\fbox{\maru*{\Rrnum{8}}}\quad
\fbox{\maru{\alphabetarray{2}}}\fbox{\maru*{\alphabetarray{2}}}\quad
\fbox{\kakko{\Rrnum{1}}}\fbox{\kakko*{\Rrnum{1}}}

\medskip
\noindent Non-matches retain normal sizing:\par
\fbox{\maru{A}}\fbox{\maru{1}}\fbox{\maru{a1}}\fbox{\maru{あ}}

\medskip
\noindent \texttt{\string\jegg}: lowercase sizing is automatic; the star
still changes only the background style.\par
\fbox{\jegg{m}}\fbox{\jegg*{m}}\quad
\fbox{\jegg{\alphabetarray{2}}}\fbox{\jegg*{\alphabetarray{2}}}\quad
\fbox{\jegg{1}}\fbox{\jegg*{1}}

\medskip
\noindent Nested/state-leak smoke test:\par
\fbox{\maru{\kakko{a}}}\fbox{\jegg{m}}\fbox{\seihou{Qjg}}

\medskip
\noindent Vertical-writing smoke test:\par
\parbox<t>{6\zw}{甲\maru{m}\kakko{\Rrnum{8}}\jegg{m}乙}
