% Regression test for the star (safe-sizing) routes at the default frame
% widths.  Compile with: latexmk -r .latexmkrc test-star-fit.tex
%
% Explicit-star material is arbitrary, so every star route that selects the
% safe-sizing path must scale it uniformly until it fits the enclosure that is
% really drawn.  The assertions live in star-fit-checks.tex; they drive the
% public commands and measure a rendered outline rather than trusting any
% constant in the package.
